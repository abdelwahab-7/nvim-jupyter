1. INTRODUCTION                                   *nvim-jupyter-introduction*

`nvim-jupyter` is an interactive Jupyter Notebook client inside Neovim.
It connects to a background Jupyter kernel, executes code blocks directly
from `.ipynb` files, and renders outputs inline. It features a Local Variable
Explorer, Undo Tree, and native `image.nvim` integration.

==============================================================================
2. INSTALLATION                                   *nvim-jupyter-installation*

Dependencies:
- Python 3 and `jupyter_client` (pip install jupyter_client)
- ImageMagick (`magick` CLI)
- [Optional] `pandas` and `tabulate` for rich dataframe rendering
- [Optional] `image.nvim` for rich inline plotting.

Check your environment via: >
    :checkhealth nvim_jupyter

==============================================================================
3. CONFIGURATION                                 *nvim-jupyter-configuration*

You can configure the plugin by calling its setup function:

>lua
    require("nvim_jupyter").setup({
      -- Whether to render HTML as images (macOS only, requires qlmanage)
      render_html_as_image = false,
      
      -- Automatically clean up /tmp/ files generated by the plugin on exit
      clean_tmp_files_on_exit = true,
      
      -- Custom Keymaps
      keymaps = {
        run_current_cell = "<leader>rc",
        run_all = "<leader>ra",
        cancel_current_cell = "<leader>kc",
        interrupt_execution = "<leader>ka",
        run_cells_above = "<leader>ru",
        run_cells_below = "<leader>rd",
        add_cell_below = "<leader>bt",
        toggle_variable_explorer = "<leader>ve",
        toggle_local_variables = "<leader>lv",
        toggle_undo_tree = "<leader>ut",
        toggle_local_undo = "<leader>lu",
      },
    })
<

==============================================================================
4. COMMANDS                                            *nvim-jupyter-commands*

`:JupyterConnect`
    Manually start or connect to the Jupyter Kernel. Note: the plugin does this
    automatically when opening an `.ipynb` file.

`:JupyterStop`
    Shutdown the background kernel process safely.

==============================================================================
5. KEYMAPS                                              *nvim-jupyter-keymaps*

These default keymaps apply to Jupyter notebook buffers (and are overridable
via `setup()`):

    <leader>rc      Run the current cell
    <leader>ra      Run all cells in the notebook
    <leader>kc      Skip/Cancel current cell
    <leader>ka      Interrupt the kernel (cancel all)
    <leader>ru      Run all cells above
    <leader>rd      Run all cells below
    <leader>bt      Add a new empty cell below
    <leader>ve      Toggle global Variable Explorer
    <leader>lv      Toggle Local Variables for current cell
    <leader>ut      Toggle notebook Undo Tree
    <leader>lu      Toggle local cell Undo Tree
    <Esc>           Toggle between Global layout view and Local cell editing
